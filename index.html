Personal backup integration

Astro Backups

Astro Backups is a private, single-user tool for keeping recoverable, encrypted copies of a personal assistant's configuration and application data in the owner's Google Drive.

What the tool does

Once configured, the tool uses rclone on the owner's computer to upload encrypted backup archives, list and verify stored backups, download archives for recovery, and remove old backups according to the configured retention settings.

Google Drive access

The owner authorizes access through Google's sign-in and consent process. The intended permission is access to files and folders created by this backup integration. Google Drive is the storage destination; this website provides information about the integration.

Encryption and recovery

Backup contents are encrypted before upload. Recovery requires the corresponding encryption passphrase or recovery key, which the owner must keep separately from the backed-up computer.

This is a personal integration, not a public backup service. Cloud connection and automatic scheduling are currently being configured.

Read the privacy policy for details about data access, storage, retention, and revoking access.

Contact

For questions about this integration, open an issue in its public repository. Do not include passwords, tokens, backup contents, or other private information.
